 Social Media Impact on Real Life 

 Project Overview
This project focuses on analyzing the impact of social media on students' real lives using Microsoft Power BI. It explores how social media usage influences students' daily activities, mental health, sleep patterns, and overall well-being.

The dashboard provides interactive visualizations and insights to understand social media usage patterns and their effects on students.

Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX (Data Analysis Expressions)
- Data Cleaning & Transformation
- Data Visualization

 Dashboard Pages
1. **Social Media Overview** – Overall project insights and key performance indicators.
2. **Usage Analysis** – Analysis of students' social media usage patterns.
3. **Mental Health Analysis** – Exploring the relationship between social media and mental health.
4. **Sleep Analysis** – Understanding social media usage and sleep patterns.
5. **Country Analysis** – Comparing social media impact across countries.
6. **Age Group Analysis** – Analyzing social media usage and impact across different age groups.

 Key Performance Indicators (KPIs)
- Total Students
- Average Daily Usage
- Heavy Users
- Average Sleep Hours
- Average Wellbeing Index

 Key Features
- Interactive dashboards
- Multiple analysis pages
- Data-driven insights
- Dynamic filtering and visualizations
- User-friendly dashboard navigation

 Project Objective
The main objective of this project is to understand how social media affects students' daily lives and identify patterns related to usage, mental health, sleep, and overall well-being.

 Conclusion
This project demonstrates my practical knowledge of Power BI, data analysis, data visualization, and dashboard development. It helped me improve my analytical thinking and ability to convert raw data into meaningful insights.
